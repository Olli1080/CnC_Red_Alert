## 2026-09-12 — Sub-milestone 1b: CODE/ compiles and links against WIN32LIB (0 errors)
[code_1b_port_log.md](code_1b_port_log.md) — `CODE/` (242 files, the authoritative Win32 object list transcribed from Westwood's own `MAKEFILE`) now compiles and links against `win32lib` under MSVC2026/x64/CMake (`redalert_code.lib` produced), down from ~20,835 errors at the first real build attempt. Two systemic root causes accounted for most of the drop: an angle-bracket include-path shadowing bug (`CODE/` listed before `WIN32LIB/INCLUDE`, silently substituting the wrong version of 7 identically-named headers) and a circular `FUNCTION.H` self-inclusion that left whole chains of derived classes seeing incomplete bases. `PaletteClass` (no surviving implementation anywhere in this GPL release, but needed by ~50 files) was reconstructed from call-site usage after an owner-approved blast-radius estimate. `NULLDLG.CPP`, `NULLMGR.CPP`, and `WOL_LOGN.CPP` excluded with documented justification (confirmed-absent proprietary/missing dependencies: Greenleaf Comm Library, `phone.h`, `PassEdit.h`). Parent plan: [../plans_wip/modernization_cmake_vcpkg.md](../plans_wip/modernization_cmake_vcpkg.md) (still in progress overall — next is sub-milestone 1c).

## 2026-09-12 — Sub-milestone 1a: WIN32LIB compiles standalone (0 errors)
[win32lib_1a_port_log.md](win32lib_1a_port_log.md) — `WIN32LIB` now builds clean under MSVC2026/x64/CMake (`win32lib.lib` produced), down from 1650 errors across 25 files at the first real build attempt. Two genuine root-cause bugs found and fixed (not workarounds): a `WWSTD.H` `#include <windows.h>` guard that broke under CMake's default `WIN32` preprocessor define, and `#pragma pack(N)` set before `<windows.h>`'s first inclusion in two audio files, which modern Windows SDK headers `static_assert` against. Several files (`MOVIE.CPP`, `AUDIO/TST.CPP`, `PLAYCD/REDBOOK.CPP`, `RAWFILE/CCFILE.CPP`, `PROFILE/PROFILE.CPP`) were excluded from the build with documented justification rather than patched, since each is genuinely out of scope, dead, or a proven-superseded duplicate. Parent plan: [../plans_wip/modernization_cmake_vcpkg.md](../plans_wip/modernization_cmake_vcpkg.md) (still in progress overall — next is sub-milestone 1b).
